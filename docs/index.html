Как запустить

  1. Клонируйте репозиторий: git clone https://github.com/OteshovTursunjan/DanielFolio.git
  2. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
  3. Создайте файл .env по образцу .env.example, если нужен ключ Gemini API.
  4. Запустите приложение на эмуляторе или устройстве.
